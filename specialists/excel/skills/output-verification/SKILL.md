# Excel output verification

**Use after:** any workbook creation, transformation, repair or delivery.

1. Confirm output exists and is distinct from source.
2. Reopen with a compatible reader; check package integrity and workbook structure.
3. Compare sheet names, dimensions, headers, required values, counts and key totals.
4. Check formulas were preserved; do not mistake cached values for recalculated results.
5. Check formatting and requested features actually supported by the tool.
6. Use Microsoft Excel for final compatibility when Office-specific behavior matters.
7. Report exact checks run and platform checks not performed.

Keep Generated, Read-back verified, Formula recalculated in Excel, VBA compiled, VBA runtime tested and Delivered as distinct evidence states.
